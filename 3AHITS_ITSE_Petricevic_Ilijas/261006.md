## Vs Code installieren
- Tastenlayout auf Deutsch umstellen mit:
```sh
setxkbmap de
```
- Gebe folgenden Code im Terminal ein 
```sh
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build
sudo apt install ./vscode.deb
code --version
```
- Um Vs Code zu starten immer:
```sh
code .
```
- Um KaliLinux herunterzufahren
```sh
shutdown -h now
```

## Github mit Terminal verbinden
- Im Terminal folgende Commands eingeben:
- Statt John Doe deinen eigenen Benutzernamen
```sh
git config --global user.name "Jon Doe"
```
- Statt deine@email.at deine Email eingeben
```sh
git config --global user.email "deine@email.at"
```
- Danach den Link vom Github-Repository kopieren (**Wichtig! Nur im Repository drinnen sein und nicht wo anders!**) und in die Klammern des folgenden Commands reinkopieren:
```sh
git clone <GitHub Repo Link>
```
