## Übung 2.1 (Netzwerk NAT/Bridged)

### Bridged

**KaliLinux -> Metasploitable**
```sh
ping 192.168.10.52 // Ip-Adresse von Metasploitable 
```

**Metasploitable -> KaliLinux**
```sh
ping 192.168.10.51 // Ip-Adresse von KaliLinux 
```

**Hostsystem -> KaliLinux & Metasploitable**
```sh
ping 192.168.10.51 // Ip-Adresse von KaliLinux
ping 192.168.10.52 // Ip-Adresse von Metasploitable
```

**KaliLinux -> Hostsystem**
```sh
ping 192.168.10.50 // Ip-Adresse vom Hostsystem
```

**Metasploitable -> Hostsystem**
```sh
ping 192.168.10.50 // Ip-Adresse vom Hostsystem
```

## Übung 2.2 (Dateitransfer per Webserver Metasploitable -> Kali)

**In Metasploitable**
```sh
echo test.txt
ps ax | sudo netstat -tlpn | grep port 80
```

**Wo legt der Webserver seine files ab?**
```
/var/www/html/
```

**In Metasploitable**
```sh
sudo mv test.txt /var/www/html/
```

**In KaliLinux**
```sh
curl http://192.168.10.52/test.txt -O
```
