### Bridged

**KaliLinux -> Metasploitable**
```sh
ping 192.168.10.52 // Ip-Adresse von Metasploitable 
```

**Metasploitable -> KaliLinux**
```sh
ping 192.168.10.51 // Ip-Adresse von KaliLinux 
```

**Hostsystem -> KaliLinux & Metasploitable**
```sh
ping 192.168.10.51 // Ip-Adresse von KaliLinux
ping 192.168.10.52 // Ip-Adresse von Metasploitable
```

**KaliLinux -> Hostsystem**
```sh
ping 192.168.10.50 // Ip-Adresse vom Hostsystem
```

**Metasploitable -> Hostsystem**
```sh
ping 192.168.10.50 // Ip-Adresse vom Hostsystem
```
