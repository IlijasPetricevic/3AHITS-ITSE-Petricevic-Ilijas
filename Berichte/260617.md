## xxd
Dateien oder Text in einen Hexadezimal-Dump (eine Spalte mit Hex-Zahlen) zu konvertieren.<br>
**Optionen:**<br>
- -p (Plain) zeigt dir nur den reinen Hex-Code einer Datei an, ohne störenden Text oder Nummern am Rand.
- -r (Reverse) arbeitet rückwärts und verwandelt einen Hex-Code wieder zurück in normalen Text oder eine Datei.

### Manchmal wird der in dem Zusammenhang (vor allem in der Netzwerktechnik) der Begriff “octet” verwendet. Was ist die Bedeutung? Gibt es einen Grund diesen Begriff zu verwenden?<br>

### Octet:
- Eine Gruppe von genau 8 Bits (Also acht 0 oder acht 1)<br>

### Warum?
- Früher war 1 Byte nicht immer genau 8 Bit lang und dieses Wort wurde dafür erfunden um genau 8 Bit zu meinen.


### xxd unterstützt eine Option -E. Was macht diese? Ist diese heutzutage noch relevant?
-E
- Ändert von ASCII auf EBCDIC (älteres Zeichenkodierungssystem)
- Fast gar nicht mehr

### Um einen dezimalen Wert (ASCII Ziffern) als Binärwert in ein File zu schreiben können folgende Befehle verwendet werden:
```sh
$ value=65534

$ printf "%.8x" $value | xxd -r -p >data.bin
```

### Was macht das printf und der Ausdruck %.8x?
- Wandelt es von einer normalen Zahl in eine Hexzahl um auf genau 8 Stellen lang
  
### Wie würdest du jemanden (mit einem Bash Grundverständnis) erklären wie diese Zeile die Aufgabenstellung löst.
- Das .x wandelt von einer normalen Zahl in einer Hexzahl um. Das .8 macht es genau 8 Stellen

### Finde einen Weg um den 4 Byte Binärwert aus der Datei wieder als Dezimalwert darzustellen. Hinweis: verwende od , mit Byte-Order big-endian.
```sh
od -t u4 -N 4 --endian = big data.bin
```

### Was macht die -i Option von xxd? Was könnte eine mögliche Anwendung sein?
- -i gibt den Inhalt einer Datei als fertigen C-Code weiter

### Mögliche Anwendung

- Standard, der genau 256 Zeichen definiert
